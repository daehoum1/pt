나는 회사 임직원들의 근태를 체크하여 특정한 기준에 따른 특별휴가(오아시스) 대상자 여부를 판별하는 업무를 수행하고 있어. 이것을 자동으로 판별하는 프로그램을 클로드 코드를 이용하여 만들고자 해. 입력으로는 엑셀 파일과 pdf 파일이 사용돼. 너가 참고할 수 있게 각각에 대한 샘플 파일을 업로드했어. 엑셀 파일에는 사원들의 이름과 근무일자(예: 2026-08-02)에 대한 열이 존재해. 그리고 출근, 퇴근, 기본 열은 각각 출근 시간(예: 8:58), 퇴근 시간(예: 18:09), 총 근무 시간(예: 9:11)이 기록되어 있어. 만약 출근 시간이나 퇴근 시간이 기록되어 있지 않은 경우에는, 출장으로 인해 직출이거나 직퇴일 수 있어. 해다 여부를 판단하기 위해서는 입력으로 들어간 pdf 파일을 참고하면 돼. 아래와 같은 양식으로 사원의 직출, 직퇴에 대한 기록이 적혀 있어.

김맹구

[직퇴 보고]

• 일시: 2026.8.3.(월)

• 출발시간: 21시 (이동시간 1시간 10분)

• 사유: 123사비창작센터 미팅, 시설 관리 후 123사비창작센터에서 직퇴합니다.

[직출 보고]

• 일시: 2026.8.5.(수)

• 출발시간: 8시 45분 (이동시간 10분)

• 사유: 여행콘텐츠최강자전 택배발송을 위해 장재우체국으로 직출합니다.

하지만, 꼭 엑셀 파일의 비어있는 출근/퇴근 시간이 pdf 파일에 기록되어 있는 것은 아니야. 사원이 깜빡하고 출퇴근 기록을 하지 않았을 수도 있어.

오아시스 대상자 선정 기준은 아래와 같아.

모든 평일(주말 제외)의 총 근무시간이 9시간 이상이어야 함.
모든 평일에 9:00 이전에 출근해야 함. (9:00는 허용)
모든 평일(주말 제외)에 출근 시간과 퇴근 시간에 대한 기록이 있어야 함. 엑셀에 없는 경우 pdf에 있어야 함.

입력으로는 엑셀 파일과 pdf 파일을 넣어줄 것이고, 출력으로는 엑셀 형식의 파일을 얻고 싶어. 기존 입력 엑셀 파일을 시작으로 하고, 비어있는 출근 시간과 퇴근 시간을 pdf 파일을 통해 기록되게 하고 싶어. 그리고 그것을 기반으로 기본(총 근무 시간) 열이 비어있는 경우에 마찬가지로 채워 줘. 오아시스 여부에 대한 열을 가장 오른쪽에 추가하여 오아시스에 해당될 경우 O로 표시하고 셀을 빨간색으로 칠해 줘. 이 엑셀 파일을 최종 산출물로 다운로드 받을 수 있게 하는 프로그램을 클로드 코드를 이용하여 만들 거야. 클로드 코드에 입력할 프롬프트를 작성해 줘.
