나 혼자 사용할 개인 일정 관리(플래너) 웹 앱을 만들어 줘.
나는 프로그래밍 초보라서 실행과 사용이 최대한 간단했으면 좋겠어.

## 1. 실행 환경
- 운영체제: [Windows / Mac]
- 내 컴퓨터에서 로컬 서버로 실행하고, 웹 브라우저에서 http://localhost:5000 으로 접속해서 사용
- 백엔드는 Python(Flask)으로 만들고, 엑셀 파일은 openpyxl로 읽고 써 줘
- 더블클릭만 하면 서버가 켜지고 브라우저가 자동으로 열리는 실행 파일을 만들어 줘
  (Windows는 start.bat, Mac은 start.command)
- 필요한 패키지는 requirements.txt로 정리해 줘

## 2. 데이터 저장 (엑셀)
- 모든 일정은 프로젝트 폴더 안의 data/planner.xlsx 파일에 저장
- 파일이 없으면 처음 실행할 때 자동으로 만들어 줘
- 열 구성: ID, 일정 이름, 종류, 중요도, 시작 시간, 종료 시간, 마감 기한, 메모, 완료 여부, 알림 발송 여부, 등록일시
- 일정을 추가·수정·삭제할 때마다 즉시 엑셀에 반영
- 엑셀 파일이 Excel 프로그램에서 열려 있어서 저장이 실패하면, 앱 화면에
  "엑셀 파일을 닫고 다시 시도해 주세요" 같은 안내를 띄워 줘
- 저장할 때마다 data/backup 폴더에 날짜별 백업을 남기고, 최근 7개만 유지해 줘

## 3. 일정 입력
- 화면 상단에 [입력] 버튼을 두고, 누르면 팝업(모달) 창에 입력 폼이 뜨게 해 줘
- 입력 항목:
  - 일정 이름 (필수)
  - 시작 시간 / 종료 시간 (달력 + 시간 선택기)
  - 종류: 드롭다운 (기본값: 업무, 공부, 개인, 약속, 기타), 새 종류를 직접 추가할 수 있게
  - 중요도: 높음 / 보통 / 낮음 (버튼 클릭으로 선택)
  - 마감 기한 (날짜 + 시간, 선택 사항)
  - 메모 (선택 사항)
- 필수 항목이 비어 있으면 안내 문구 표시, Enter로 저장, ESC로 닫기
- 등록된 일정을 클릭하면 같은 폼이 열려서 수정 / 삭제 / 완료 처리를 할 수 있게 해 줘

## 4. 보기 화면
- 일간 / 주간 / 월간 탭으로 전환, [이전] [다음] [오늘] 버튼으로 이동
- 일간: 시간대별 타임라인
- 주간: 월요일부터 일요일까지 7일
- 월간: 달력 형태, 날짜 칸에 일정 이름 표시, 많으면 "+3개"처럼 줄여서 표시
- 종류별로 색을 구분하고, 중요도 '높음'은 눈에 띄게 표시
- 완료한 일정은 흐리게 + 취소선
- 마감까지 24시간 이내인 일정은 강조 표시
- 달력 구현에 FullCalendar 같은 라이브러리를 써도 좋아

## 5. 마감 알림
- 마감 기한이 1시간 이하로 남은 '미완료' 일정에 대해 자동으로 알림
- 브라우저 알림(Notification API)을 사용하고, 처음 접속할 때 알림 권한을 요청
- 권한이 거부되었거나 지원되지 않으면 화면 안에 팝업 + 알림음으로 대신 알려 줘
- 1분마다 확인하고, 같은 일정은 한 번만 알리도록 '알림 발송 여부'를 엑셀에 기록
- 설정 메뉴에 [알림 테스트] 버튼을 넣어서 알림이 잘 오는지 바로 확인할 수 있게 해 줘

## 6. 디자인
- 전체적으로 하늘색 톤
  - 배경: #F0F8FF, 카드/패널: 흰색, 메인 색: #87CEEB, 버튼/강조: #3A9AD9
- 둥근 모서리, 부드러운 그림자, 깔끔하고 여백 있는 디자인

- 노트북 화면 기준으로 만들되, 창 크기를 줄여도 깨지지 않게

## 7. 진행 방식
- 코드를 쓰기 전에 폴더 구조와 구현 계획을 먼저 보여 주고, 내가 확인한 뒤에 진행해 줘
- 완성 후 직접 실행해서 다음을 테스트해 줘:
  일정 추가 → 엑셀 저장 확인 → 서버 재시작 후 다시 불러오기 → 수정/삭제 → 알림 동작
- README.md에 설치 방법, 실행 방법, 자주 생기는 문제 해결법을 초보자 기준으로 한국어로 써 줘
