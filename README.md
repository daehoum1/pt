# 추가 기능 : 세금계산서 품명 자동 분류(AI 품목 분류)

프로그램은 세금계산서의 **품명**을 읽은 후, 이를 회사에서 사용하는 **표준 품목명**으로 자동 분류하는 기능을 구현한다.

단순히 품명을 그대로 입력하는 것이 아니라, 다양한 표현을 하나의 표준 품목으로 통일해야 한다.

---

# 동작 방식

세금계산서 PDF를 분석하여 품명을 추출한다.

예를 들어 다음과 같은 품명이 입력될 수 있다.

* A4 복사용지
* 복사용지 A4
* 더블에이 복사용지
* A4 Paper
* HP LaserJet 토너
* 삼성 MLT-D111S
* USB Memory 64GB
* LAN Cable CAT6
* HDMI Cable
* 사무용 의자
* 철재 캐비닛
* 컴퓨터 본체
* 노트북
* 모니터
* 마우스
* 키보드

이러한 품명을 분석하여 아래와 같은 표준 품목으로 자동 변환한다.

예시

| 세금계산서 품명        | 표준 품목    |
| --------------- | -------- |
| A4 복사용지         | 복사용지     |
| 복사용지 A4         | 복사용지     |
| Double A        | 복사용지     |
| HP Paper        | 복사용지     |
| 삼성 토너           | 프린터 토너   |
| MLT-D111S       | 프린터 토너   |
| HP 85A          | 프린터 토너   |
| USB Memory      | USB 메모리  |
| USB Flash Drive | USB 메모리  |
| LAN Cable       | 랜케이블     |
| CAT6 Cable      | 랜케이블     |
| HDMI Cable      | HDMI 케이블 |
| Notebook PC     | 노트북      |
| Laptop          | 노트북      |
| Desktop         | 데스크톱     |
| Monitor         | 모니터      |
| Office Chair    | 사무용 의자   |

---

# AI 분류 방식

품명이 정확하게 일치하지 않아도 의미가 같으면 동일한 품목으로 분류한다.

예를 들어

"A4 Copier Paper"

↓

복사용지

또는

"삼성전자 MLT-D111S 정품"

↓

프린터 토너

처럼 의미 기반으로 분류한다.

가능하면 키워드 매칭과 AI 의미 분석을 함께 사용한다.

우선순위는 다음과 같다.

1. 품목 사전(Dictionary) 매칭
2. 유사어(Synonym) 매칭
3. 키워드 분석
4. AI 의미 분석
5. 어느 항목에도 해당하지 않으면 원래 품명을 그대로 사용

---

# 품목 사전 관리

품목 사전은 코드에 하드코딩하지 않는다.

JSON 또는 YAML 파일로 관리한다.

예시

```json
{
  "복사용지": [
    "A4 복사용지",
    "복사지",
    "A4 Paper",
    "Double A",
    "Copy Paper"
  ],
  "프린터 토너": [
    "토너",
    "MLT-D111S",
    "HP 85A",
    "Laser Toner"
  ],
  "USB 메모리": [
    "USB",
    "USB Memory",
    "USB Flash"
  ],
  "랜케이블": [
    "LAN Cable",
    "CAT5",
    "CAT6",
    "RJ45 Cable"
  ]
}
```

사용자는 이 JSON 파일만 수정하여 새로운 품목을 추가할 수 있어야 한다.

프로그램을 수정하지 않아도 품목 분류가 가능하도록 설계한다.

---

# 다중 품목 처리

세금계산서에 품목이 여러 개인 경우 각각을 개별적으로 분류한다.

예시

품명

* A4 복사용지
* HP 토너
* USB Memory

↓

분류 결과

* 복사용지
* 프린터 토너
* USB 메모리

문서에도 각각 표시한다.

---

# 문서 자동 입력

자동 분류된 표준 품목명을 다음 문서에 동일하게 입력한다.

* 발주서
* 지출결의서
* 물품검수조서

세 문서의 품목명이 모두 동일하도록 한다.

---

# 분류 결과 확인

문서를 생성하기 전에 사용자가 분류 결과를 확인할 수 있는 화면을 제공한다.

예시

세금계산서 품명 → 표준 품목

A4 복사용지 → 복사용지

HP 85A → 프린터 토너

USB Flash Drive → USB 메모리

사용자가 필요하면 표준 품목명을 수정할 수 있도록 한다.

수정한 결과를 기준으로 문서를 생성한다.

---

# 학습 가능한 품목 사전

사용자가 분류 결과를 수정하면 그 결과를 품목 사전에 저장할 수 있도록 한다.

예를 들어

"Laser Printer Toner"

↓

사용자가

"프린터 토너"

로 수정하면

다음부터는 자동으로 "프린터 토너"로 분류된다.

품목 사전(JSON/YAML)에 자동 반영하거나 별도의 사용자 사전(user_dictionary.json)에 저장하는 구조로 구현한다.

---

# 구현 요구사항

품목 분류 기능은 별도의 모듈(Item Classifier)로 구현한다.

예시

```text
item_classifier.py

class ItemClassifier

    load_dictionary()

    classify()

    similarity_match()

    ai_match()

    save_user_dictionary()
```

향후 수천 개 이상의 품목을 관리할 수 있도록 확장 가능한 구조로 설계한다.

---

# 최종 처리 흐름

1. 세금계산서 PDF 업로드
2. OCR 및 텍스트 추출
3. 품명 추출
4. 품목 사전 및 AI 기반 자동 분류
5. 사용자가 분류 결과 확인 및 필요 시 수정
6. 수정 결과 저장(선택)
7. 날짜 자동 생성
8. 발주서 생성
9. 지출결의서 생성
10. 물품검수조서 생성
11. PDF 변환
12. ZIP 다운로드

모든 문서는 **자동 분류된 표준 품목명**을 사용하며, 품목 분류 로직은 설정 파일과 사용자 사전을 통해 지속적으로 확장·학습할 수 있도록 설계한다.
