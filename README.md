Python과 Streamlit을 이용하여 회의 음성 분석 및 경영 보고서 생성 프로그램을 만들어 주세요.

사용자가 MP3, M4A, WAV 또는 MP4 형식의 긴 회의 음성파일을 업로드할 수 있어야 합니다.

프로그램은 다음 순서로 작동해야 합니다.

1. 업로드된 음성파일을 faster-whisper로 한국어 텍스트로 변환합니다.
2. 전사 결과에는 각 문장의 시작 시간과 종료 시간을 포함합니다.
3. 긴 회의록은 적절한 길이의 구간으로 나누어 처리합니다.
4. 회의록에서 다음 정보를 추출합니다.
   - 견적
   - 가격
   - 비용
   - 예산
   - 매출
   - 할인
   - 단가
   - 총액
   - 부가세
   - 납기 및 계약 조건
5. 경쟁업체 또는 경쟁사와 관련된 내용을 추출합니다.
6. 각 추출 결과에는 업체명, 핵심 내용, 금액, 관련 품목, 타임스탬프, 근거 문장, 신뢰도를 포함합니다.
7. 추출 결과를 기반으로 다음 항목을 포함하는 경영 보고서를 작성합니다.
   - 회의 핵심 요약
   - 견적 및 비용 정보
   - 경쟁사별 주요 동향
   - 경쟁사의 강점과 약점
   - 우리 회사에 대한 위협과 기회
   - 향후 경영 방향
   - 우선순위별 실행 권고사항
8. 회의에서 확인된 사실, AI의 해석, 권고사항을 명확히 구분합니다.
9. 근거가 부족한 내용은 단정하지 말고 '추가 확인 필요'로 표시합니다.
10. 모든 핵심 분석에는 근거가 된 타임스탬프와 원문을 표시합니다.
11. 결과를 화면에서 검토하고 수정할 수 있게 합니다.
12. 최종 결과를 Word와 PDF 파일로 다운로드할 수 있게 합니다.

프로젝트 구조를 먼저 설계하고, 필요한 파일을 생성한 다음 단계별로 구현해 주세요.
API 키는 .env 파일로 관리하고 코드에 직접 입력하지 마세요.
