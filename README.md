세금계산서의 날짜가 입력되었을 떄, 이전에 작성되어야 했던 세 종류 문서를 자동으로 PDF파일로 생성해 주는 프로그램을 만들고 싶어. 발주서, 지출결의서, 물품검수조서를 생성해야 하고 세금계산서를 PDF의 형식으로 입력했을 때, 각 문서가 자동으로 생성되게 해야 해. 이때 세금계산서의 날짜를 인식하여 발주서, 지출결의서, 물품검사조서의 날짜가 자동으로 생성되어야 해. 발주서의 경우에는 세금계산서의 날짜를 기준으로 일주일 전의 임의의 평일로 되어야 하고, 지출결의서는 계산서와 동일한 날짜로, 물품검사조서는 세금계산서의 날짜의 다음 주의 임의의 평일로 되어야 해. 세금계산서를 업로드했을 때 자동으로 나머지 세 종류의 문서가 생성되도록 프로그램을 만들 것이고, 클로드 코드를 이용할 거야. 이때 클로드 코드에게 입력해야 할 프롬프트를 작성해 줘.
