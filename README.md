나는 클로드 코드를 이용하여 개인 플래너 앱을 만들고자 해. 나의 여러 일정들을 관리하는데 사용할 거야. 이 프로그램은 나 혼자 사용할 거야. 나는 여러 일정들을 입력이라는 버튼을 눌렀을 때, 시간과 일정 이름, 일정의 종류, 중요도, 마감기한 등을 편하게 기입하고 싶어. 이때 나는 등록한 일정들이 일 단위, 주 단위, 월 단위로 확인할 수 있게 하고 싶고, 마감 기한이 1시간 남은 일정에 대해서 자동으로 알림을 해 주는 기능을 넣고 싶어. 웹 브라우저에서 프로그램이 나타났으면 좋겠고, 하늘색 톤이었으면 좋겠어. 데이터들은 엑셀 파일의 형식으로 내 컴퓨터에 저장되게 해 줘. 이러한 프로그램을 만들고자 할 때, 클로드 코드에게 입력할 프롬프트를 추천해 줘.
