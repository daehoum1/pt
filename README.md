
나는 하나의 보고서가 있고 이 보고서를 변경했을 때, 변경된 보고서에서 추가된 부분이 어딘지 형광펜으로 칠해 주는 프로그램을 만들고 싶어. 이 두 보고서는 pdf 형식으로 되어 있어. 두 개의 업로드 버튼이 있어서 PC에서 두 개의 보고서 파일을 이전 버전과 최신 버전을 업로드 할 수 있게 해 주고, 출력으로는 최신 버전의 보고서에서 변경된 부분이 형광펜이 칠해진 보고서가 pdf 파일로 나와 다운로드 받을 수 있게 해 줘. python 파일을 실행시켜서 돌릴 수 있게 하지 말고, html 형식으로 편하게 화면에서 이를 진행할 수 있게 해  줘.
